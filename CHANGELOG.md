## 1.0.0-alpha.0 (2026-10-25)

### 🚀 Features

- `@nib-ui/tokens` builds the design tokens from DTCG source into `tokens.css` (CSS custom properties with `light-dark()` themes, `data-theme`, `data-density` and reduced motion), `tailwind.css` (`@theme inline` aliases with radius and shadow namespaces reset) and `tokens.json` for tools. ([14c0508](https://github.com/nib-ui/nib/commit/14c0508))
- `@nib-ui/core` gains the controller interface types (`Instance`, `Part`, `Intent`, `NibEvent`), the clock and geometry seams with null adapters and `systemClock`, and `@nib-ui/core/testing` with `createTestHost()`, fake clock and geometry, and the APG conformance runner. ([b0de214](https://github.com/nib-ui/nib/commit/b0de214))
- `@nib-ui/dom` gains the browser side of core's seams: `runIntents()` (focus, scroll-into-view, announce; returns intents whose element is missing), `announce()` through one polite and one assertive live region per page, `toNibEvent()` (keyboard, input and composition events, IME-aware), `uniqueId()` for vanilla JS, and `domGeometry()` (element boxes, visual viewport, and a frame-batched `watch`). ([#20](https://github.com/nib-ui/nib/issues/20))
- The four bindings gain their generic bridge. `@nib-ui/js`: `define(name, setup)`, idempotent `init(root)` / `destroy(root)` for `data-nib` elements (id, page language and real host passed to each setup), `bind(instance, targets)`, and the `@nib-ui/js/auto` entry. `@nib-ui/react` and `@nib-ui/vue`: `useController(create, options)`. `@nib-ui/svelte`: `controller(create, options)`, a store. Each runs intents after its framework commits and renders the same markup on server and client. `@nib-ui/dom` adds `domAttrs()`, `domHost()` and `documentLocale()`; `@nib-ui/core/testing` adds `createTestList()`. ([#21](https://github.com/nib-ui/nib/issues/21))
- `@nib-ui/css` publishes `@nib-ui/css/nib.css`: one minified file that declares the layer order (`nib.theme, nib.base, nib.components, nib.utilities`) and bundles the tokens. Base and components join it as they land. ([#23](https://github.com/nib-ui/nib/issues/23))
- `@nib-ui/css` also publishes every component on its own as `@nib-ui/css/components/<name>.css`, for pages that load only what they use (with `@nib-ui/tokens/tokens.css`). ([#22](https://github.com/nib-ui/nib/issues/22))
- `@nib-ui/css` adds the button (`nib-button` with `--primary`, `--outline`, `--ghost`, `--destructive`, `--lg`, the printed shortcut `nib-button__key`) and the `nib-action-row` it sits in. States come from `aria-pressed` (cursor block), `disabled` and `aria-disabled`; forced colours and right-to-left are covered. ([#24](https://github.com/nib-ui/nib/issues/24))
- Listbox, the first interactive component, across every package: `createListbox` in `@nib-ui/core/listbox` (APG listbox: current option by `aria-activedescendant`, chosen value by `aria-selected`, Enter/Space/click choose, typeahead ignoring case and diacritics, Home/End, disabled options, `multiple` with `aria-checked`, rebindable `keys`) and its APG table in `@nib-ui/core/listbox/apg`; `useListbox` in `@nib-ui/react/listbox` and `@nib-ui/vue/listbox`; `createListboxStore` in `@nib-ui/svelte/listbox`; `data-nib="listbox"` in `@nib-ui/js/listbox` (options from `data-nib-option`, changes as `nib:change`); and `nib-listbox` in `@nib-ui/css`. The conformance runner focuses the target before its keys, as a browser does. ([#25](https://github.com/nib-ui/nib/issues/25))
- `@nib-ui/css` gains its base layer: reset, type role classes (`nib-text-*`, `nib-kicker`, `nib-num`), `nib-prose` at the 68ch reading width, `nib-container`, the ruled `nib-grid`, `nib-with-side`, `nib-pane-header`, the `nib-skip` link and a 2px accent focus ring. Caps come from `--nib-caps` and switch off for scripts without case; any region can set `data-theme` and repaints its own ground. ([254a8c1](https://github.com/nib-ui/nib/commit/254a8c1))
- `@nib-ui/css` adds `nib-breadcrumb` (mono meta trail, slashes as decoration, current segment in ink) and `nib-pagination` (`← PREV · 2 / 9 · NEXT →` in mono labels, arrows that swap under right-to-left, an `aria-disabled` step on the first or last page, and a spoken status label). ([66282c5](https://github.com/nib-ui/nib/commit/66282c5))
- CLI: `nib theme check [file.css …]` in `@nib-ui/cli` reads a theme's `--nib-*` colours (hex, or `light-dark()` of two hex colours), lays them over Nib's palette and runs every contrast, tag, colour-vision and hue-collision rule on both themes. Errors print as proof marks and exit with 1; with no files it reads the `theme` file named in `nib.config.json`. No telemetry. ([#54](https://github.com/nib-ui/nib/pull/54), [#105](https://github.com/nib-ui/nib/pull/105))
- Combobox: `createCombobox` in `@nib-ui/core/combobox` (APG combobox with list autocomplete; filtering with `Intl.Collator` ignoring case and diacritics; nothing filters or acts while an IME composes; a native manual popover placed below the field) and `createMatcher` for match ranges; `useCombobox` (React, Vue), `createComboboxStore` (Svelte), `data-nib="combobox"` (vanilla); `nib-combobox__list` / `__match` in `@nib-ui/css`. `NibEvent` carries the field's `value` on input and composition events; the vanilla `bind()` writes `value` as the property; React gives controlled fields `onChange`. ([#48](https://github.com/nib-ui/nib/pull/48), [#101](https://github.com/nib-ui/nib/pull/101))
- Command palette: `createCommandPalette` in `@nib-ui/core/command-palette` (a modal dialog holding a combobox over the commands; filtering that ignores case and diacritics; a page-wide shortcut, `mod+k` by default, with `mod` as ⌘ on Apple platforms and Ctrl elsewhere; `onRun` once the dialog has closed) and `matchShortcut` / `printShortcut` / `ariaShortcut`; `useCommandPalette` (React, Vue), `createCommandPaletteStore` (Svelte), `data-nib="command-palette"` (vanilla); `listenShortcut` in `@nib-ui/dom`; `nib-command-palette` and `nib-hotkey` in `@nib-ui/css`. A new `modal` intent opens and closes a `<dialog>` with `showModal()` / `close()`. ([#49](https://github.com/nib-ui/nib/pull/49), [#103](https://github.com/nib-ui/nib/pull/103))
- `@nib-ui/css` adds content blocks: `nib-section` and `nib-hero`, `nib-tile` (product, post, feature and plan parts, `--recommended`), `nib-row` (chosen, checked, `--new`, `--flagged`, `--ruled`, `--ghost`), `nib-pane` and `nib-stat`, the static `nib-table` with `nib-bulk-bar`, and `nib-hue-<hue>` / `nib-mark` for the hue a block draws with. The CSS build now starts from an empty `dist`. ([1456e3c](https://github.com/nib-ui/nib/commit/1456e3c))
- Data grid: `createDataGrid` in `@nib-ui/core/data-grid` (APG data grid with one tab stop; sorting that is stable and locale-aware, or `manualSort`; row selection with a select-all header; Enter/F2 cell editing with `onEdit`; column resize by drag or Alt+Left/Right; paging; windowed rendering from 1,000 rows on a page) and `sortRows` / `windowOf`; `useDataGrid` (React, Vue), `createDataGridStore` (Svelte), `data-nib="data-grid"` (vanilla, reads its rows from the table markup); `nib-data-grid` in `@nib-ui/css`. `NibEvent` carries `clientX` and `capturePointer()` on pointer events and `scrollTop` / `clientHeight` on scroll. A send or `update()` made from a callback inside a controller's reduce now applies after reduce's own state is committed. ([#51](https://github.com/nib-ui/nib/pull/51), [#104](https://github.com/nib-ui/nib/pull/104))
- Date picker: `createDatePicker` in `@nib-ui/core/date-picker` (APG date picker dialog grid; single dates and ranges; ISO `YYYY-MM-DD` values on the Gregorian calendar whatever the locale; the first day of the week from the locale; min, max and disabled dates); `useDatePicker` (React, Vue), `createDatePickerStore` (Svelte), `data-nib="date-picker"` (vanilla); `nib-calendar` in `@nib-ui/css`. ([#51](https://github.com/nib-ui/nib/pull/51), [#104](https://github.com/nib-ui/nib/pull/104))
- Dialog: `createDialog` in `@nib-ui/core/dialog` on the native `<dialog>` opened and closed by invoker commands (`commandfor` / `command`), named by its title and description, reporting open and close; `useDialog` (React, Vue), `createDialogStore` (Svelte), `data-nib="dialog"` (vanilla); and `nib-dialog` (`--drawer`, bottom sheet under 30rem, scrim) in `@nib-ui/css`. ([#45](https://github.com/nib-ui/nib/pull/45), [#99](https://github.com/nib-ui/nib/pull/99))
- Disclosure and accordion: `createDisclosure` and `createAccordion` in `@nib-ui/core/disclosure` (APG patterns; controlled or uncontrolled; `multiple` and `collapsible`; arrows, Home and End between accordion buttons), bindings `useDisclosure` / `useAccordion` (React, Vue), `createDisclosureStore` / `createAccordionStore` (Svelte) and `data-nib="disclosure"` / `data-nib="accordion"` (vanilla), and `nib-disclosure__trigger` / `__panel` and `nib-accordion` in `@nib-ui/css`. ([ec332f3](https://github.com/nib-ui/nib/commit/ec332f3))
- `@nib-ui/css` adds `nib-empty` (ghost rows, a mono label, a sentence and one action), `nib-ghost`, the `nib-spinner` (✻ stepping 110ms frames, still under reduced motion) inside `nib-loading`, `nib-progress` (a native progress drawn as a 2px rule) and `nib-media-placeholder`. ([24e4bcc](https://github.com/nib-ui/nib/commit/24e4bcc))
- `@nib-ui/fonts` ships Inter and JetBrains Mono as self-hosted variable WOFF2 (Latin, Latin Extended, Vietnamese subsets) with `fonts.css` (`@font-face` + `unicode-range`, under the names the tokens use) and both OFL licences. Import `@nib-ui/fonts/fonts.css` before `@nib-ui/css/nib.css`; without it the token stacks fall back to system fonts. ([1555642](https://github.com/nib-ui/nib/commit/1555642))
- `@nib-ui/css` adds form fields: `nib-input` (input, textarea, select), `nib-choice` (checkbox and radio printing `[x]` / `(•)` glyphs over a native input), `nib-switch` (`role="switch"`, knob-less `ON` / `OFF`), `nib-field` with label, `OPTIONAL` marker, hint and error, `nib-fieldset`, and `nib-error-summary`. States come from `aria-invalid`, `:checked`, `:indeterminate` and `:disabled`; rows are 44px tall on touch. ([3b40b75](https://github.com/nib-ui/nib/commit/3b40b75))
- `@nib-ui/icons` ships the first 17 icons (chevrons, prev / next arrows, close, check, plus, minus, search, calendar, copy, external, menu, warning, info) as an SVG sprite, one ES module per icon and a CSS mask (`icons.css`, `class="nib-icon nib-icon-<name>"`). The build rejects any source that breaks the drawing laws: `<path>` only, straight 0° / 45° / 90° segments, half-pixel grid, 1px or 2px strokes on whole pixels, 16 or 20 box. ([21b7491](https://github.com/nib-ui/nib/commit/21b7491))
- Menu button: `createMenu` in `@nib-ui/core/menu` (APG menu button on a native popover; items, checkbox and radio items, arrows, Home, End, typeahead, Enter/Space choose and close, Tab closes), `useMenu` (React, Vue), `createMenuStore` (Svelte), `data-nib="menu"` (vanilla, with `nib:select`), and `nib-menu` / `__item` / `__separator` in `@nib-ui/css`. Core gains a `popover` intent (show or hide a native popover), run by `@nib-ui/dom`; `place()` gains `measurePlacement` and `samePlacement` helpers. ([9432d8b](https://github.com/nib-ui/nib/commit/9432d8b))
- Popover and placement: `place()` in `@nib-ui/core/place` (side and align in logical terms, flip, shift, fit; pure), and `createPopover` in `@nib-ui/core/popover` on the native `popover` attribute (top layer, Escape and outside click close it, focus returns), placed beside its trigger and kept there while the page moves. Bindings `usePopover` (React, Vue), `createPopoverStore` (Svelte), `data-nib="popover"` (vanilla); `nib-popover` in `@nib-ui/css`. `NibEvent` gains `newState` for toggle events; the React binding turns a `style` string into an object and knows `popoverTarget`. ([118467b](https://github.com/nib-ui/nib/commit/118467b))

([11497c9](https://github.com/nib-ui/nib/commit/11497c9))
