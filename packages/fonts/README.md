# @nib-ui/fonts

Inter and JetBrains Mono for Nib, self-hosted: variable WOFF2 (weight axis, upright) in Latin,
Latin Extended and Vietnamese subsets. Nothing is loaded from Google Fonts.

```css
@import '@nib-ui/fonts/fonts.css';
@import '@nib-ui/css/nib.css';
```

The faces are named `Inter` and `JetBrains Mono`, the first names in `--nib-font-sans` and
`--nib-font-mono`. Without this package those stacks fall back to system fonts.

Fonts: SIL Open Font License 1.1 (`dist/LICENSE-inter.txt`, `dist/LICENSE-jetbrains-mono.txt`),
taken from the Fontsource builds of the upstream releases. Package code: MIT.
