`@nib-ui/css` adds page chrome: `nib-header` (sticky 48px bar, `nib-nav` mono words with a 2px accent underline on `aria-current="page"`, utility words, and a MENU fallback that opens the nav below the bar without JavaScript under 30rem), `nib-side-nav` (vertical nav for the side column, current item with a 2px accent rule) and `nib-footer` (ruled link columns and a meta row).
