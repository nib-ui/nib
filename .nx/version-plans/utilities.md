`@nib-ui/css` adds the opt-in `utilities.css` (and `utilities.json`), generated from the tokens in `nib.utilities`: display, flex and grid columns, spacing steps on logical properties, density cell padding, font family / weight / caps / alignment / measure, text and surface colour roles, hue fills and 2px hue rules, `nib-visually-hidden`, and `nib-at-sm|md|lg-` container-query variants of the layout utilities inside a `nib-cq` container. Every class is prefixed `nib-`; no radius, shadow, gradient or blur.
