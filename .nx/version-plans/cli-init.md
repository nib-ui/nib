nib: minor
---

CLI: `nib init` writes `nib.config.json` (preset, CSS kind, entry and theme paths), a CSS entry for Nib alone or under Tailwind v4, and an empty theme file; it asks at a terminal, takes `--preset`, `--css` and `--dir` flags, keeps existing files, and prints the `<html>` attributes of the preset's default theme and density. No telemetry.
